# Store Management System

A simple command-line store application built with Python and object-oriented programming (OOP).

![Python](https://img.shields.io/badge/Python-3.x-blue?logo=python)
![OOP](https://img.shields.io/badge/Concept-OOP-orange)
![License](https://img.shields.io/badge/License-MIT-green)

## Features

* Display available products
* Show total inventory quantity
* Create and process orders
* Validate user input
* Handle product and inventory errors
* Track temporary shopping carts

## Project Structure

```text
.
├── main.py
├── products.py
├── store.py

```

## Run the application

Make sure Python 3 is installed, then run:

```bash
python main.py
```
